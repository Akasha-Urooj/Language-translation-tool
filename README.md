# 🌍 Language Translation Tool

A simple and user-friendly language translation application built using **Python, Streamlit, Google Translate, and gTTS**.

## 🚀 Features

* 🌐 Translate text between multiple languages
* 🔤 Select source and target languages
* ⚡ Fast translation
* 🔊 Text-to-Speech for translated text
* 📥 Download translated text
* 🎨 Simple and clean Streamlit interface

## 🛠️ Technologies

* Python
* Streamlit
* Deep Translator
* Google Translate
* gTTS

## 📁 Project Structure

```text
Language_Translation_Tool/
│
├── app.py

```

## ⚙️ Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

```bash
streamlit run app.py
```

## 💡 How It Works

1. Enter the text you want to translate.
2. Select the source language.
3. Select the target language.
4. Click **Translate**.
5. View the translated text.
6. Download or listen to the translation.
